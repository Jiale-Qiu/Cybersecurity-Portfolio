# Reference Sheet

<details>

<summary>Decimal ↔ Hexadecimal ↔ Binary Conversion Table (Up to 15)</summary>

`0x` is the prefix to denote a hex value. `0b` is the prefix to denote a binary value.

| Decimal | Hexadecimal | Binary |
| ------- | ----------- | ------ |
| 0       | 0x0         | 0000   |
| 1       | 0x1         | 0001   |
| 2       | 0x2         | 0010   |
| 3       | 0x3         | 0011   |
| 4       | 0x4         | 0100   |
| 5       | 0x5         | 0101   |
| 6       | 0x6         | 0110   |
| 7       | 0x7         | 0111   |
| 8       | 0x8         | 1000   |
| 9       | 0x9         | 1001   |
| 10      | 0xA         | 1010   |
| 11      | 0xB         | 1011   |
| 12      | 0xC         | 1100   |
| 13      | 0xD         | 1101   |
| 14      | 0xE         | 1110   |
| 15      | 0xF         | 1111   |

</details>
